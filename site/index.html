Spot it. Dive. Captured.

Gannet is a native screen capture tool that lives in the macOS menu bar. Press a shortcut, pick a region, a window or the whole screen, mark it up, and it's on your clipboard.

From shortcut to clipboard in a second

The screen freezes the moment you press the shortcut, so menus, tooltips and video stay exactly as they were.

▭

Region

Drag over the frozen screen with a live size readout, then mark it up right there.

◫

Window

Click any window to capture it whole, without the drop shadow.

▣

Full screen

Every display at its full resolution, one image each.

↗

Mark up

Rectangles, ellipses, lines, arrows, pen, text, numbered steps and mosaic, in 8 colours and 3 sizes, with undo.

⌘

Your shortcuts

Record any shortcut in Settings. Gannet warns when one clashes with macOS or another capture.

↓

Copied and saved

Done copies the capture and saves a PNG to the folder you choose. ⌘S saves anywhere, ⌘C only copies.

Three shortcuts to remember

The system's own, with ⌃ in place of ⌘, so they never clash. Change them any time.

⌃⇧4
Capture a region
⌃⇧5
Capture a window
⌃⇧3
Capture the full screen

Install

Signed with a Developer ID and notarized by Apple, so it opens without warnings.

  1. Download the DMG from the latest release and drag Gannet onto Applications.
  2. Open Gannet. It lives in the menu bar: look for the viewfinder icon (there is no Dock icon).
  3. On the first capture, allow Screen Recording for Gannet, then choose Reopen Gannet in Settings ▸ Permissions.

Or build it yourself (Rust stable):

git clone https://github.com/cuong95nddev/gannet
cd gannet && scripts/install.sh

Where it's headed

Gannet follows the feature set of FastStone Capture, on macOS. See the roadmap.

  • Region, window and full screen captures
  • Mark up with undo and redo
  • Shortcuts you choose, save folder, permissions
  • Redaction that can't be read back
  • Scrolling capture of long pages
  • Repeat last region, delayed capture
  • An editor window for past captures
  • Screen recording to MP4 and GIF
