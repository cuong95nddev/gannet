A fast, native screen capture tool that lives in the macOS menu bar.

Download for macOS
Free and open source · macOS 12.3+ · Apple Silicon and Intel

Features

  • Region, window or full screen, on a shortcut. The screen freezes the moment you press it.
  • Mark up with boxes, arrows, pen, text, numbered steps and mosaic.
  • Enter copies the capture and saves it as a PNG.
  • Your own shortcuts and save folder, in Settings.

Install

  1. Download the DMG and drag Gannet onto Applications.
  2. Open it: it lives in the menu bar.
  3. Allow Screen Recording on the first capture.
git clone https://github.com/cuong95nddev/gannet
cd gannet && scripts/install.sh
