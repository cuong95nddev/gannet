Features

  • Region, window, full screen or a scrolling region, on a shortcut. The screen freezes the moment you press it.
  • Mark up with boxes, ellipses, lines, arrows, pen, text, numbered steps and mosaic.
  • Enter copies the capture and keeps it in the library; save as PNG, JPEG or BMP.
  • A library that keeps every capture encrypted on disk, in folders, with layers you can edit later.
  • Your own shortcuts and save folder, in Settings.

Install

  1. Download the DMG and drag Gannet onto Applications.
  2. Open it: it lives in the menu bar.
  3. Allow Screen Recording on the first capture.
git clone https://github.com/cuong95nddev/gannet
cd gannet && scripts/install.sh
